## 2. 공통 기술 규격 (두 시안 모두)

- 단일 self-contained HTML 파일. 빌드 없음. Lenis importmap(unpkg) + 인라인 CSS/JS — Lumora 스펙의 페이지 셸(어댑티브 rem 그리드, 스크롤 락, scrollTo, 스프링 헬퍼, 텍스트 리빌, reduced-motion 처리)을 **그대로 재사용**한다.
- **폰트: Pretendard Variable** (한글 프리미엄의 핵심 레버, 무료):
  `<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css" />` → `font-family:'Pretendard Variable',Pretendard,'Onest',sans-serif`. 워터마크·큰 영문 숫자는 같은 패밀리 유지(별도 디스플레이 폰트 도입 금지 — 절제).
- 이미지 에셋 **0장** (성능 예산·저작권·0원 기조). 사진 없이 타이포·여백·모션·해어라인으로 프리미엄을 만든다. Lumora의 사진 liquid-reveal은 **이식하지 않는다** (아래 시안별 히어로 대체 참조).
- 반응형: Lumora 브레이크포인트 그대로 (sm 640 / md 768 / lg 1024, rem 그리드). 모바일 첫인상 최우선 — 폰에서 히어로 3초 안에 "누구·몇 년·무엇"이 읽혀야 한다.
- 언어: 한국어 본문 + 영문 워터마크/라벨 최소 사용. `lang="ko"`.
- 로더: Lumora 로더 이식 (000→100, 1300ms, 마크+태그라인). 태그라인 = §3 히어로 서브 첫 문장.
- 내비: Home / 성과 / 경력 / 역량 / 연락. 연락 = mailto (모달·폼 없음 — 시안 단계 단순화, NavMenu 오버레이·RequestModal은 생략).
- 접근성: skip link, :focus-visible, aria-current, reduced-motion 전부 유지.

## 5. 시안 B "Ink Cinema" (v23-B-dark.html)

같은 구조·같은 카피를 **다크 퍼스트**로 반전. D(시네마틱 프리미엄) 픽 반영 — 단 화려함이 아니라 "어두운 정장" 무드. 
- 토큰 반전: page `#0a0a0a` / text `#f4f3f1` / muted `rgba(244,243,241,.55)` / hairline `rgba(255,255,255,.08)` / surface `#141312` / 카드 `#121110` + ring `rgba(255,255,255,.06)`. Accent는 ember 계열 유지 `#cf8047`(밝은 쪽) — 다크 위에서 점·카운터·언더라인에만 아껴 쓴다.
- 히어로: 풀블리드 잉크. 필름 그레인(같은 feTurbulence, opacity ≤0.05) + **커서 스포트라이트** (radial-gradient rgba(207,128,71,.07), 반경 ~40rem, pointermove 추적, reduced-motion 시 정적 중앙 배치) + 워터마크 `HENRY LIM` rgba(255,255,255,.04). 대형 타이포가 주인공.
- 성과 카드: 다크 위 카드라서 반전 — 카드가 살짝 **밝은** `#f1f0ee` 잉크-반전 카드(텍스트 #111)로 떠오르게 = 시네마틱 대비 순간. 카드 워터마크 숫자는 rgba(17,17,17,.08).
- Stats 패널: 라이트 패널(#f1f0ee, 텍스트 #111)로 반전 — 페이지 유일한 밝은 블록.
- 경력·역량 행: 다크 해어라인 행, hover 시 `rgba(255,255,255,.04)` 필.
- CreateBand: `Launch`(surface) / `Operate`(accent 그라데이션 #cf8047→#97501f) / `→`(light 반전) / `Handover`(ghost).
- 로더: 동일 (다크라 자연스럽게 이어짐 — 로더 배경과 페이지가 같은 잉크).

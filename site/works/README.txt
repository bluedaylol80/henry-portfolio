확장자는 jpg / png / webp. 파일이 있으면 카드에 자동으로 뜨고, 없으면 빈 슬롯으로 남는다.

지켜야 할 것
- 파일명은 반드시 소문자. GitHub Pages는 리눅스라 대소문자를 구분한다 —
  LYN.jpg는 윈도우에서만 열리고 배포하면 404다(2026-08-14 실사례).
- 한 장에 300KB를 넘기지 말 것. 4.85MB짜리가 들어온 적 있다(재인코딩으로 58KB가 됐다).
- 카드 배경으로 꽉 차게 깔리니 가로 1200px 이상이면 고화질 화면에서도 또렷하다.
- 저작권은 각 게임사에 있다. 어디까지 쓸지는 사람이 판단한다.

_unused/ 는 카드에서 뺀 이미지 보관함이다(공개 배포에 포함되지 않음).

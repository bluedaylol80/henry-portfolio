- README.md는 v21 시절 내용으로 낡음 — 믿지 말 것(정본은 docs/DESIGN.md의 포인터).
- **정적 스크린샷에는 리퀴드 리빌이 안 보인다**(포인터 이벤트 필요) — shot-reveal.mjs로만 판정.
- 리빌 레이어에 외부 이미지 URL 금지(저작권·사진 0장 방침). 전부 코드 생성.
- **정적 스크린샷으로는 리빌 타이밍을 못 본다** — 촬영 스크립트가 `is-in`을 강제해 종단상태만 찍는다.
  타이밍 검증은 계단 스크롤 실주행(요소별 적용 `--rd`·`is-in` 회수)으로만 가능. 3회차 방식 참고.
- 리빌 `--rd`는 이제 **작성값 그대로 쓰이지 않는다**(런타임 배치 정규화, 08-13 3회차).
  마크업에서 큰 --rd를 새로 쓸 때 "같이 보이는 그룹인가"를 먼저 볼 것 — 아니면 어차피 0으로 깎인다.
- shot-file.mjs는 로더 제거를 기다린 뒤 찍는다(08-13 수정). **고정 sleep으로 되돌리지 말 것** — 로더 퇴장
  구간에 걸려 빈 샷이 나온다. 풀페이지 샷은 리빌 종단상태를 강제한 화면(레이아웃 판정용)임을 감안할 것.

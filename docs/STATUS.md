- shot-file.mjs 출력 파일명 고정 → 반복마다 새 폴더 필수.

- README.md는 v21 시절 내용으로 낡음 — 믿지 말 것(정본은 docs/DESIGN.md의 포인터).
- **정적 스크린샷에는 리퀴드 리빌이 안 보인다**(포인터 이벤트 필요) — shot-reveal.mjs로만 판정.
- 리빌 레이어에 외부 이미지 URL 금지(저작권·사진 0장 방침). 전부 코드 생성.
- **정적 스크린샷으로는 리빌 타이밍을 못 본다** — 촬영 스크립트가 `is-in`을 강제해 종단상태만 찍는다.
  타이밍 검증은 계단 스크롤 실주행(요소별 적용 `--rd`·`is-in` 회수)으로만 가능. 3회차 방식 참고.
- 리빌 `--rd`는 이제 **작성값 그대로 쓰이지 않는다**(런타임 배치 정규화, 08-13 3회차).
  마크업에서 큰 --rd를 새로 쓸 때 "같이 보이는 그룹인가"를 먼저 볼 것 — 아니면 어차피 0으로 깎인다.
- **Puppeteer `page.screenshot({clip})`은 문서 좌표계**다. `getBoundingClientRect()`(뷰포트 기준)를 그대로 넣으면
  scrollY=0인 헤더·히어로만 우연히 맞고 푸터는 엉뚱한 빈 영역이 찍힌다 — `+scrollX/+scrollY` 필수(08-13 4회차에 삭제).
  `scripts/shot-clip.mjs`는 `element.screenshot()`이라 이 함정이 없다(요소 기준). 좌표를 직접 넣을 때만 주의.
- 포커스 상태를 촬영할 땐 탭 직후 **1100ms 이상** 대기 — Lenis 스무스 스크롤이 안착하기 전 좌표를 읽으면 빗나간다.
- 호버 반응을 새로 추가할 땐 `@media (hover:hover) and (pointer:fine)` 안에만 쓰지 말 것 —
  키보드는 포인터와 무관해 그 블록에 갇히면 탭 사용자에게 아무 반응이 없다. `:focus-visible` 대응을 **미디어 밖에** 함께 쓸 것(08-13 4회차).
- 링을 그리는 요소와 둥근 박스가 다르면 링이 각지게 나온다(래퍼/자식 분리 패턴). 새 컴포넌트도 `.pill` 방식대로
  **둥근 자식에 outline을 얹을 것**.
- shot-file.mjs는 로더 제거를 기다린 뒤 찍는다(08-13 수정). **고정 sleep으로 되돌리지 말 것** — 로더 퇴장
  구간에 걸려 빈 샷이 나온다. 풀페이지 샷은 리빌 종단상태를 강제한 화면(레이아웃 판정용)임을 감안할 것.

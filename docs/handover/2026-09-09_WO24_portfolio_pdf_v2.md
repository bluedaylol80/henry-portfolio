# WO-24 2026-09-09 — 포트폴리오 PDF v2 · 가로 슬라이드형 (R1 Fable 5.1 설계 → R3 Opus 시공)

본부장 판정(09-09): 현행 PDF(A4 세로, 텍스트 표 위주 7쪽)는 **제출용 포트폴리오로 무리** — 이미지가 없고 옛 포트폴리오·레퍼런스 구조가 반영되지 않았다(WO-18 설계 누락). 결재: **판형 = 16:9 가로 슬라이드형**, 사진 = 옛 포트폴리오 캡처 재사용 + 달콤·원더피플 새 캡처(본부장 제공) + 공개 키 비주얼·스토어 스크린샷.
원칙 유지: 사이트가 텍스트 원천(문구 두 벌 금지, `build-print`가 사이트에서 읽어 조립) · 🔴 내부 수치·실명·원본 기획서 금지(새니타이즈 사본만) · **이미지 채택은 사람 판정(팩트시트 §6)** — 채택표에 O가 붙은 이미지만 빌드에 들어간다. 이 repo는 PUBLIC — 채택된 이미지만 `site/pdf/img/`에 둔다.

## 0. 참고 구조(반영 필수)
- 옛 포트폴리오(2021, 38장): 프로젝트마다 **개요 1장**(좌: 키 비주얼·기간·플랫폼/장르 불릿·주요 업무 목록, 우: 주요 진행 업무&성과 불릿에 강조색) + **Comment&성과 1~3장**(기획서·지표·인게임 캡처 2~6장 + 하단 요약 불릿·화살표 결과). Career Milestone은 가로 타임라인 그래픽.
- 레퍼런스(타인 문서, 레이아웃만): 표지→인덱스 1장→프로젝트별 도입(회색 풀블리드+큰 번호+ABOUT 박스 4줄+스샷 2×2)→주요업무→세부 작업(문제→해결 빨간 강조+캡처 나란히).
- 새 PDF는 **사례 중심(판단→행동→결과)** 서사는 유지하되, 위 두 구조의 시각 장치(키 비주얼·캡처 그리드·큰 KPI·타임라인 그래픽)를 얹는다.

## 1. 판형·공통
- `@page{size:338.67mm 190.5mm; margin:0}`(16:9, PPT 표준). 슬라이드 안쪽 여백 14mm. 종이 룩 유지(사이트 토큰·정적 Pretendard). 슬라이드 번호 우하단 `n / N`(puppeteer footer 대신 CSS로, 폰트 통일).
- 공통 헤더: 좌상단 작은 섹션 라벨(눈썹) + 회사·프로젝트명, 우상단 상태 pill(실제 출시/소프트런칭/종료). 이미지 캡션은 11pt 회색, 저작권 문구는 이미지 있는 슬라이드마다 하단 1줄(퍼블리셔명, 사이트 `.card-rights`와 동일 문안).
- 이미지: `site/pdf/img/<slug>/<file>.jpg` 폭 ≤1600px 재인코딩, 총 PDF ≤ 8MB. 슬롯에 채택 이미지가 없으면 회색 "이미지 대기" 박스로 그리되 **최종 빌드는 대기 박스 0개 assert**.

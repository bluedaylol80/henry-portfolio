## 디자인 규칙(지시 원문 요약)
- 폰트 SUIT(가변, `site/deck/fonts/SUIT-Variable.woff2`, OFL). 컬러 배경 `#F5F5F5` / 메인 `#26262B` / 서브 `#E62B1E` / 텍스트 `#1A1A1A`. 보조색은 텍스트색의 투명도·명도 조정만(예: `#1A1A1A` 60%·35%·12%).
- 기본 장=연회색 배경. 강조 장=텍스트색(`#1A1A1A`) 배경+서브컬러 포인트. 표지=차콜(`#26262B`) 기반 어둡게.
- 군더더기 없이. 데이터·내용이 바로 읽히게. 데이터는 그래프·플로우차트·다이어그램으로(표 나열 금지). 전후·비교는 진한 회색 vs 빨강으로 강조 지점을 명확히.
- 아이콘은 단순 선형(인라인 SVG, 외부 아이콘 폰트 금지). 여백이 남으면 내용과 어울리는 이미지(사이트 `site/pdf/img/`·`site/works/`)를 투명도·그라데이션 도형과 함께, 텍스트 가독성 유지.
- 표지: 제목("사용자 요구를 제품 방향으로, 개발 우선순위를 실행으로")과 어울리는 **추상 모션그래픽**이 계속 움직임 — 왼쪽에서 흩어진 점들(요구)이 가운데 렌즈/호를 지나며 정렬된 흐름선(실행)으로 오른쪽으로 흘러가는 SVG+CSS 애니메이션, 느린 루프, 점 몇 개만 서브컬러. `prefers-reduced-motion`이면 정지.

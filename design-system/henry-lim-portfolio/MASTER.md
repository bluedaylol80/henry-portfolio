## 0. 도구 제안을 채택하지 않은 이유 (기록)

`ui-ux-pro-max --design-system`은 "Modern Dark (Cinema)" 패턴에 **Orbitron + JetBrains Mono / 블루 #1E40AF + 그린 #059669**를 제안했다. 이 사이트에는 **채택하지 않는다**:

- 본부장이 v20에서 **Fraunces + Pretendard 900 / amber #F5B041 + 네이비 5단**을 LOCKED로 확정했고, 그 위에 v21 서사·데모·방이 전부 지어져 있다.
- 세 스킬 모두 같은 원칙을 명시한다 — *"The brief wins. 확정된 아이덴티티를 취향으로 갈아엎는 것은 실패"*(impeccable), *"redesign - preserve는 기존을 유지"*(taste-skill).
- 따라서 도구에서 취하는 것은 **품질 게이트(§5 체크리스트·우선순위표)**뿐이고, 시각 언어는 아래 §1~§4가 정본이다.

🟡 **알아둘 충돌 1건**: taste-skill은 `Fraunces`를 "LLM이 남용하는 디스플레이 세리프"로 기본 사용 금지 목록에 올린다. 여기서는 **브랜드 확정값이므로 유지**한다(브리프 우선 원칙). 본부장이 원할 때만 재검토 대상.

## 2. 타이포

- **디스플레이**: `Fraunces Variable`(EN) / **한글은 `:lang(ko) .u-display`로 Pretendard 900 승격** — 한글 세리프 대체를 쓰지 않기 위한 장치.
- **본문·UI**: `Geist Variable` → 한글 글리프는 `Pretendard`로 폴백.
- **라벨·증거 숫자**: `IBM Plex Mono`(`.u-fig` = tabular-nums). 한글 모노는 자간 축소 규칙 적용됨.
- 본문 하한 16px · 줄간 1.5+ · 측정폭 65ch 내.

## 3. 모션 (LOCKED §3.3)

- 이징은 **`lux` `cubic-bezier(0.32,0.72,0,1)`** 와 **`out4` `cubic-bezier(0.22,1,0.36,1)`** 둘만 쓴다. `ease-in-out`·`linear` 금지.
- **핀(pin)은 페이지당 1개**(홈 Act 2). 늘리면 모바일 이탈·멀미.
- **정지 상태 = 완성 상태**: 연출이 실패하거나 `prefers-reduced-motion`이어도 정보는 100% 읽혀야 한다.
- 연출 엔진(gsap)은 **lazy 경계 뒤**. Home에서 정적 import 금지(예산 붕괴).

## 4. 레이아웃·예산

- 컨테이너 `container-std`, 브레이크포인트 375 / 768 / 1024 / 1440 실측.
- **가로 넘침 0px**가 합격선(5모드 하니스가 매번 확인).
- **크리티컬 JS ≤ 150KB gz**(현재 136.5KB). `manualChunks` 재도입 금지.
- 딥링크는 Pages SPA 폴백 특성상 404 응답(화면 정상) — 프리렌더 전까지 알려진 상태.

## 5. 품질 게이트 (ui-ux-pro-max 우선순위표에서 채택)

배포 전 이 순서로 본다. 1·2는 CRITICAL.

- [ ] **접근성** — 대비 4.5:1 · 포커스 링 제거 금지 · 아이콘 단독 버튼에 라벨 · alt
- [ ] **터치·인터랙션** — 최소 44×44px · 간격 8px+ · 즉시(0ms) 상태 변화 금지
- [ ] **성능** — 이미지 지연 로드 · 공간 예약(CLS) · eager 예산 준수
- [ ] **스타일 일관성** — 이모지를 아이콘으로 쓰지 않는다 · 액센트 1개 고정
- [ ] **반응형** — 가로 스크롤 0 · 고정 px 컨테이너 금지 · 확대 차단 금지
- [ ] **타이포·색** — 본문 16px+ · 회색 위 회색 금지 · 토큰만 사용(생 hex 금지)
- [ ] **모션** — 150~300ms · 의미 있는 모션만 · reduced-motion 존중
- [ ] **키보드** — 전 인터랙션 도달 가능 · Esc로 닫기
